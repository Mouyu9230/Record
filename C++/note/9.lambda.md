# C++ Lambda 知识点总结

## 1. 什么是 Lambda

Lambda 是 C++ 中的匿名函数，用于在局部位置快速定义一段可调用逻辑。

相比普通函数：

* 不需要函数名
* 可直接写在使用位置
* 可捕获外部局部变量
* 非常适合 STL 与临时逻辑

现代 C++ 中大量使用 lambda。

---

# 2. 基本语法

```cpp id="g4i6d4"
[capture](params) -> return_type {
    body
};
```

常见形式：

```cpp id="e3jwrh"
[](int a, int b){
    return a + b;
}
```

其中：

* `[]`：捕获列表
* `()`：参数列表
* `->`：返回值类型（通常可省略）

---

# 3. 捕获列表（核心）

Lambda 最大特点是能访问外部局部变量。

## 值捕获

```cpp id="jjlwmr"
[x]
```

复制变量，内部修改不影响外部。

---

## 引用捕获

```cpp id="syh4rz"
[&x]
```

直接操作原变量。

---

## 全部捕获

```cpp id="pbqk7f"
[=]   // 全部值捕获
[&]   // 全部引用捕获
```

---

# 4. mutable

默认情况下，值捕获变量在 lambda 内不可修改。

使用：

```cpp id="g17yeg"
mutable
```

后可修改副本，但不会影响外部变量。

---

# 5. 常见用途
## STL 算法
最常见于：

* `sort`
* `for_each`
* `find_if`
* `priority_queue`

例如自定义排序：

```cpp id="12uyjy"
sort(v.begin(), v.end(),
[](int a, int b){
    return a > b;
});
```
---

## DFS / BFS

Lambda 可直接捕获图、vis 数组等局部变量，避免使用全局变量。

递归 lambda 通常配合：

```cpp id="x7h1eu"
function<>
```

使用。

---

# 6. Lambda 与普通函数区别

| 对比        | 普通函数 | Lambda |
| --------- | ---- | ------ |
| 是否需要名字    | 是    | 否      |
| 是否能写在局部   | 一般   | 可以     |
| 是否能捕获局部变量 | 不方便  | 可以     |
| 是否适合临时逻辑  | 一般   | 非常适合   |

---

# 7. 底层本质

Lambda 本质是编译器生成的匿名类对象。
其核心是重载：

```cpp id="8k6c25"
operator()
```

因此 lambda 本质属于“函数对象（functor）”。
