## C++ 智能指针简洁总结

C++11 提供了三种智能指针，都位于：

```cpp
#include <memory>
```

| 智能指针         | 中文      | 所有权 | 可拷贝 | 主要用途        |
| ------------ | ------- | --- | --- | ----------- |
| `unique_ptr` | 独占智能指针  | 独占  | ❌   | 资源唯一拥有者     |
| `shared_ptr` | 共享智能指针  | 共享  | ✅   | 多个对象共同管理资源  |
| `weak_ptr`   | 弱引用智能指针 | 不拥有 | ✅   | 解决循环引用、观察对象 |

---

### 1. unique_ptr：独占所有权

同一时间只能有一个指针拥有对象。

```cpp
auto p = std::make_unique<int>(10);
```

特点：

* 不允许拷贝
* 支持移动

```cpp
auto p2 = std::move(p);
```

适用：

* RAII
* 文件、锁、socket 等资源管理
* 默认首选智能指针

---

### 2. shared_ptr：共享所有权

多个指针共同管理同一个对象。

```cpp
auto p1 = std::make_shared<int>(10);
auto p2 = p1;
```

内部维护引用计数：

```cpp
std::cout << p1.use_count(); // 2
```

最后一个 `shared_ptr` 销毁时释放对象。

适用：

* 多个模块共享资源
* 对象生命周期无法明确归属

---

### 3. weak_ptr：弱引用

不拥有对象，不增加引用计数。

```cpp
std::shared_ptr<int> sp = std::make_shared<int>(10);
std::weak_ptr<int> wp = sp;
```

访问：

```cpp
if (auto p = wp.lock()) {
    std::cout << *p;
}
```

适用：

* 解决 `shared_ptr` 循环引用
* 观察对象是否存在

---

## 一句话记忆

```text
unique_ptr：只能我拥有。

shared_ptr：大家一起拥有。

weak_ptr：我只看看，不拥有。
```

---

## 使用建议

```text
优先使用 unique_ptr
需要共享时使用 shared_ptr
避免循环引用时使用 weak_ptr
```

现代 C++ 中，大多数资源管理都应使用智能指针，而尽量避免直接使用：

```cpp
new
delete
```

因为智能指针能够自动释放资源，实现 RAII，减少内存泄漏和异常安全问题。
