## 给你一个下标从 0 开始、由 n 个整数组成的数组 nums 和一个整数 target 。你的初始位置在下标 0 。在一步操作中，你可以从下标 i 跳跃到任意满足下述条件的下标 j ：0 <= i < j < n-target <= nums[j] - nums[i] <= target返回到达下标 n - 1 处所需的 最大跳跃次数 。如果无法到达下标 n - 1 ，返回 -1 。
5.10 daily
简单的dp,好久没push东西了刷个小绿点
解：
```
class Solution {
public:
    int maximumJumps(vector<int>& nums, int target) {
        vector<int> dp;
        dp.push_back(0);
        int size=nums.size();
        for(int i=1;i<size;i++){
            int maybemax=-1;
            for(int j=0;j<i;j++){
                if(dp[j]==-1){
                    continue;
                }
                if(abs(nums[j]-nums[i])<=target){
                    if(dp[j]>maybemax){
                        maybemax=dp[j];
                    }
                }
            }
            if(maybemax==-1){
                dp.push_back(-1);
                continue;
            }
            dp.push_back(maybemax+1);
        }
        reverse(dp.begin(),dp.end());
        if(dp[0]==0){
            return -1;
        }
        return dp[0];
    }
};
```
